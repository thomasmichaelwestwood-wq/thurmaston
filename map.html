Interactive map — where buildings used to be

An interactive map of Thurmaston showing buildings and places that used to stand in the village.

Our interactive map will develop over time

This map only shows buildings and places we can back with a real source — a photo, a resident's account, a map or a directory listing. As more residents come forward, we'll keep adding to it. If you know a building that used to stand here — a name, roughly where it was, roughly when it went — tell us or use the form below.

    Map data © OpenStreetMap contributors. Pin locations for lost buildings are approximate.
