Add a grave to the cemetery map

Fill in what you know, click the exact spot on the aerial photo, then press "Save this grave" — it's written straight to the site, no separate admin page needed. If no GitHub token is set up below, it falls back to giving you values to copy into the Graves collection in /admin/ instead.

One-time setup (GitHub token, what3words key, reference points)

Use a fine-grained token (github.com → Settings → Developer settings → Personal access tokens → Fine-grained), scoped to only this repository, with only "Contents: Read and write" permission, and a real expiry date. Stored only in this browser — never sent anywhere except GitHub's own API.

Free from what3words.com's developer/API section.

Reference points

Pick 2–3 spots you can point to precisely on the photo (a corner building, a road junction). For each: click "Set point on photo", then click that exact spot, then type its real latitude/longitude (found by right-clicking the spot on Google Maps).

This is only for clicking on here — the photo shown on the live site is whatever's uploaded via the Cemetery collection's overview photo field in /admin/ (a one-time step, separate from this tool).
